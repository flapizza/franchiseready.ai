# Vision

The FranchiseReady Assessment is not a questionnaire.

It is an intelligence engine.

Every answer contributes to a continuously evolving understanding of the candidate.

The assessment is the first step in building the Candidate DNA that powers:

- Mission Control
- Candidate 360
- Discovery Copilot
- Brand Matching
- Referral Package
- Consultant Dashboard
- AI Meeting Intelligence

The assessment should feel conversational, intelligent, and personalized.

---

# Core Principles

## 1. Every Question Has a Purpose

No question exists simply because it has always been asked.

Every question must produce one or more intelligence signals.

---

## 2. Intelligence Over Data Collection

The objective is not collecting answers.

The objective is understanding people.

---

## 3. Adaptive Assessment

The assessment changes based on previous answers.

Candidates should never answer irrelevant questions.

---

## 4. Consultant First

Every output must make the consultant more effective.

---

## 5. Candidate Friendly

Candidates should enjoy completing the assessment.

It should feel like a guided conversation rather than a long form.
